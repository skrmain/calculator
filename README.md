# calculator

[![Netlify Status](https://api.netlify.com/api/v1/badges/f6cdfa2c-a82f-4cc0-9269-24f6cd7d3e2a/deploy-status)](https://app.netlify.com/projects/skrcalculator/deploys)

A lightweight, responsive calculator built as an installable Progressive Web App (PWA), featuring keyboard input and offline support.

**Live demo:** [skrcalculator.netlify.app](https://skrcalculator.netlify.app/)

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview
```

## Features

- Support KeyBoard typing
- Installable
- Works Offline
- Fully Responsive for Mobile also
- CSS Grid Based Styling

## Tech Stack

- [Vite](https://vite.dev/)
- [Sass (SCSS)](https://sass-lang.com/)
- [Netlify](https://www.netlify.com/) (hosting and deploy previews)
- [PWA Docs](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps)
