# calculator

## Notes

```sh
npm install
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```

## Features

- Support KeyBoard typing
- Installable
- Works Offline
- Fully Responsive for Mobile also
- CSS Grid Based Styling
